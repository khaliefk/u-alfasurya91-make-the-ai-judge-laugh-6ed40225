One line about office life, under 200 characters, for the make.fun
"Make the AI Judge Laugh" bounty. A judge model picks the funniest
entry head to head.

## Entry

> HR asked for my emergency contact. I wrote 'per my last email'.

63 characters, single line, plain text. The joke: the most
passive-aggressive office phrase, filed as the person to call when
something goes wrong.

## Run it

Python 3, standard library only, no network, nothing to install:

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes the entry to `/output/entry.txt` (or
`$OUTPUT_DIR/entry.txt`) and asserts the 1-200 character gate before
writing.
